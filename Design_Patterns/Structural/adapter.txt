The programming problem:-

(XML)                        (JSON)----> It's read only/closed source.

The concept and reasoning:-

Adapter pattern-> special "wrapper" class that catches calls from one object, translates the data/interface into a 2nd object and then passes it along.

Reasoning:-
-> Completely incompatible interface.
-> Single responsibility principle-> The data conversion code is separate from our core-business logic.
