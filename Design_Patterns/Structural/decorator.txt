Decorator Pattern:-

-> Coffee shop
-> Basic coffee-> CoffeeWithMilk --> CoffeeWithSugar---> CoffeeWithMilkAndSugar.

Extend caramel, vanilla, chocolate.

Inheritance-> class explosion.

Composition instead of inheritance(use).

Create "wrapper" objects (decorators).

Base object-> dynamic "wrap" inside layers of decorator at runtime.

#Reasoning:-

-> Allow us to add new behaviour / responsibility dynamically at runtime.
-> Single Responsibility Principle (SRP) -> Keep classes small and focused.
-> Open/Closed Principle (OCP) -> Open for extension, closed for modification.
