The command Pattern:- Every graphical application and text editor.

# The intuition:- Universal smart home remote control.
-> 4 blank buttons.
-> Button-> device (mapping) device agnostic.

Bad way:- if(button==1) tv->turnOn() inside remote control class.

#Prob 1:- Remote toghtly coupled to the TV and lights.
#Prob 2:- Undo feature is hard to implement.

# Solution:- Command Pattern.

# The concept and reasoning:-
-> functional "req" -> physical standalone object.
tv->turnOn() -> little capsule object -> TurnOnCommand.

button-> click-> open capsule ->execute().

# Reasoning:-
1) Decoupling:- Button(Sender) -> which device it is controlling->execute().
         ;whatever command object.

2) The magic of UNDO:- Command -> physical object-> save in an array/stack-> UNDO-> most recent command object from the stack-> undo() method.
